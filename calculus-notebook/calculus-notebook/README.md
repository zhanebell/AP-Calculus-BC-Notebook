# Calculus Notebook

This project is a web application designed to serve as a digital notebook for AP Calculus BC studying. It allows users to create, view, and search through daily notes, providing a structured and accessible way to organize study materials.

## Project Structure

The project consists of the following files and directories:

- **index.html**: The main entry point for the web app, which includes links to the CSS and JavaScript files and provides the layout for the notebook interface.
  
- **css/styles.css**: Contains styles for the web app, implementing a dark mode theme with a very dark black background and white text, along with color coding for key terms.

- **js/app.js**: Handles the main functionality of the web app, including loading the daily notes and managing navigation between them.

- **js/search.js**: Implements the search functionality, allowing users to search for key terms across the notes.

- **notes/**: A directory containing individual HTML files for each day of notes from April 30, 2025, to May 13, 2025.

## Usage

1. Open `index.html` in a web browser to access the notebook interface.
2. Navigate through the daily notes using the provided links.
3. Use the search functionality to find key terms across all notes.
