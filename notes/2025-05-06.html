Introduction to Differential Equations

What is a Differential Equation?

A differential equation is an equation containing derivatives of a function. They are used to describe rates of change in physical, biological, and economic systems.

On the AP Calculus BC exam, you'll primarily work with first-order differential equations (containing only first derivatives) and simple second-order differential equations.

Common Forms

  • First-order: \(\frac{dy}{dx} = f(x,y)\)
  • Separable: \(\frac{dy}{dx} = g(x) \cdot h(y)\)
  • Autonomous: \(\frac{dy}{dx} = f(y)\) (depends only on y)
  • Linear: \(\frac{dy}{dx} + P(x)y = Q(x)\)
  • Logistic: \(\frac{dy}{dt} = ky(L-y)\) where L is the carrying capacity

Separation of Variables

Method

For equations of the form \(\frac{dy}{dx} = g(x) \cdot h(y)\):

  1. Rearrange to separate variables: \(\frac{1}{h(y)} \cdot \frac{dy}{dx} = g(x)\)
  2. Multiply both sides by dx: \(\frac{1}{h(y)} \, dy = g(x) \, dx\)
  3. Integrate both sides: \(\int \frac{1}{h(y)} \, dy = \int g(x) \, dx\)
  4. Solve for y as a function of x

Example: \(\frac{dy}{dx} = xy^2\)

Step 1: Separate variables: \(\frac{1}{y^2} \, dy = x \, dx\)

Step 2: Integrate both sides: \(\int \frac{1}{y^2} \, dy = \int x \, dx\)

Step 3: Solve: \(-\frac{1}{y} = \frac{x^2}{2} + C\)

Step 4: Solve for y: \(y = -\frac{1}{\frac{x^2}{2} + C} = -\frac{2}{x^2 + 2C}\)

The general solution is \(y = -\frac{2}{x^2 + 2C}\) or \(y = -\frac{2}{x^2 + K}\) where K is an arbitrary constant.

Particular Solutions

To find a particular solution, use an initial condition (x₀, y₀) to determine the value of the constant C:

  1. Substitute the initial condition into the general solution
  2. Solve for the constant C
  3. Substitute C back into the general solution

Slope Fields and Direction Fields

What is a Slope Field?

A slope field (or direction field) is a graphical representation of a first-order differential equation \(\frac{dy}{dx} = f(x,y)\).

At each point (x,y) in the plane, we draw a small line segment with slope f(x,y).

The resulting pattern of slopes shows how solutions to the differential equation behave.

Interpreting Slope Fields

  1. Solution curves are paths that follow the direction of the slope field at every point
  2. If all slopes in a horizontal line are the same, the DE is autonomous \(\frac{dy}{dx} = f(y)\)
  3. Horizontal line segments indicate where \(\frac{dy}{dx} = 0\) (critical points)
  4. Vertical patterns indicate potential asymptotes or boundaries

Example: Analyzing the Slope Field for \(\frac{dy}{dx} = x - y\)

For this differential equation:

  • When y = x, the slope is 0 (horizontal line segments along the line y = x)
  • Above the line y = x, slopes are negative
  • Below the line y = x, slopes are positive
  • Solution curves tend to approach the line y = x as x increases
You should be able to sketch segments at key points in a slope field and identify which solution curve passes through a given point.

Logistic Differential Equations

Logistic Growth Model

The logistic differential equation is given by:

\(\frac{dy}{dt} = ky(L-y)\) or \(\frac{dy}{dt} = ky(1-\frac{y}{L})\)

Where:

  • \(k\) is the growth rate constant
  • \(L\) is the carrying capacity (maximum sustainable population)
  • \(y\) is the population at time \(t\)

Solution to the Logistic Equation

The solution to the logistic differential equation is:

\(y(t) = \frac{L}{1 + Ae^{-kt}}\)

Where \(A\) is determined by the initial condition \(y(0) = y_0\):

\(A = \frac{L - y_0}{y_0}\)

Example: Logistic Growth

A population follows the logistic model \(\frac{dP}{dt} = 0.5P(1-\frac{P}{1000})\) with \(P(0) = 100\).

Step 1: Identify k = 0.5 and L = 1000

Step 2: Calculate A = \(\frac{L-y_0}{y_0} = \frac{1000-100}{100} = 9\)

Step 3: Write the solution: \(P(t) = \frac{1000}{1 + 9e^{-0.5t}}\)

Step 4: Analyze the solution:

  • As t → ∞, P(t) → 1000 (carrying capacity)
  • The population grows most rapidly at the inflection point when P = 500

Euler's Method

Numerical Approximation

Euler's method is a numerical technique for approximating solutions to differential equations when analytical solutions are difficult or impossible to find.

For a differential equation \(\frac{dy}{dx} = f(x,y)\) with initial condition \(y(x_0) = y_0\):

Euler's Method Formula

\(y_{n+1} = y_n + h \cdot f(x_n, y_n)\)

Where:

  • \(h\) is the step size (Δx)
  • \(x_{n+1} = x_n + h\)
  • \(f(x_n, y_n)\) is the derivative evaluated at the current point

Example: Applying Euler's Method

Use Euler's method with step size h = 0.2 to approximate y(0.6) for the differential equation \(\frac{dy}{dx} = x + y\) with initial condition y(0) = 1.

n xₙ yₙ f(xₙ,yₙ) = xₙ + yₙ yₙ₊₁ = yₙ + h·f(xₙ,yₙ)
0 0 1 0 + 1 = 1 1 + 0.2(1) = 1.2
1 0.2 1.2 0.2 + 1.2 = 1.4 1.2 + 0.2(1.4) = 1.48
2 0.4 1.48 0.4 + 1.48 = 1.88 1.48 + 0.2(1.88) = 1.856
3 0.6 1.856 - -

Therefore, y(0.6) ≈ 1.856 using Euler's method with h = 0.2.

Error in Euler's Method

Euler's method has a local error of O(h²) and a global error of O(h).

To improve accuracy:

  • Decrease the step size h
  • Use improved methods like the midpoint method or Runge-Kutta methods
