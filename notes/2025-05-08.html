Introduction

Today we'll explore alternative coordinate systems and function representations, including parametric equations, polar coordinates, and vector-valued functions, as well as beginning our study of infinite series.

Parametric Equations

Definition

A parametric curve is defined by a set of equations:

\(x = f(t)\) and \(y = g(t)\)

where \(t\) is a parameter, typically representing time.

Derivatives with Parametric Equations

For a parametric curve \(x = f(t)\) and \(y = g(t)\):

\(\frac{dy}{dx} = \frac{\frac{dy}{dt}}{\frac{dx}{dt}} = \frac{g'(t)}{f'(t)}\) provided \(f'(t) \neq 0\)

\(\frac{d^2y}{dx^2} = \frac{d}{dt}\left(\frac{dy}{dx}\right) \cdot \frac{dt}{dx} = \frac{d}{dt}\left(\frac{g'(t)}{f'(t)}\right) \cdot \frac{1}{f'(t)}\)

Example: Motion Along a Parametric Curve

For the parametric equations \(x = t^2\) and \(y = t^3 - 3t\), find \(\frac{dy}{dx}\) and \(\frac{d^2y}{dx^2}\) at \(t = 2\).

\(f'(t) = 2t\) and \(g'(t) = 3t^2 - 3\)

\(\frac{dy}{dx} = \frac{g'(t)}{f'(t)} = \frac{3t^2 - 3}{2t} = \frac{3(t^2 - 1)}{2t}\)

At \(t = 2\): \(\frac{dy}{dx} = \frac{3(4 - 1)}{4} = \frac{9}{4}\)

For \(\frac{d^2y}{dx^2}\), we calculate \(\frac{d}{dt}\left(\frac{g'(t)}{f'(t)}\right) \cdot \frac{1}{f'(t)}\)

\(\frac{d}{dt}\left(\frac{3(t^2 - 1)}{2t}\right) = \frac{6t \cdot 2t - 3(t^2 - 1) \cdot 2}{(2t)^2} = \frac{12t^2 - 6t^2 + 6}{4t^2} = \frac{6t^2 + 6}{4t^2} = \frac{3(t^2 + 1)}{2t^2}\)

\(\frac{d^2y}{dx^2} = \frac{3(t^2 + 1)}{2t^2} \cdot \frac{1}{2t} = \frac{3(t^2 + 1)}{4t^3}\)

At \(t = 2\): \(\frac{d^2y}{dx^2} = \frac{3(4 + 1)}{4 \cdot 8} = \frac{15}{32}\)

Arc Length for Parametric Curves

Arc Length Formula

For a parametric curve given by \(x = f(t)\) and \(y = g(t)\) over the interval \(t \in [a, b]\):

\(L = \int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} \, dt = \int_a^b \sqrt{[f'(t)]^2 + [g'(t)]^2} \, dt\)

Example: Arc Length Calculation

Find the arc length of the curve given by \(x = 3\cos t\) and \(y = 3\sin t\) for \(t \in [0, \pi]\).

\(f'(t) = -3\sin t\) and \(g'(t) = 3\cos t\)

\(L = \int_0^{\pi} \sqrt{(-3\sin t)^2 + (3\cos t)^2} \, dt = \int_0^{\pi} \sqrt{9\sin^2 t + 9\cos^2 t} \, dt\)

\(= \int_0^{\pi} \sqrt{9(\sin^2 t + \cos^2 t)} \, dt = \int_0^{\pi} 3 \, dt = 3\pi\)

This makes sense since we've described a semicircle of radius 3, which has arc length \(3\pi\).

Polar Coordinates

Definition

In polar coordinates, a point is represented by \((r, \theta)\), where:

  • \(r\) is the distance from the origin
  • \(\theta\) is the angle from the positive x-axis

Conversion between polar and Cartesian coordinates:

  • \(x = r\cos\theta\)
  • \(y = r\sin\theta\)
  • \(r^2 = x^2 + y^2\)
  • \(\tan\theta = y/x\) (when \(x \neq 0\))

Derivatives in Polar Form

For a polar curve \(r = f(\theta)\):

\(\frac{dy}{dx} = \frac{r'\sin\theta + r\cos\theta}{r'\cos\theta - r\sin\theta}\)

where \(r' = \frac{dr}{d\theta}\)

Area in Polar Coordinates

The area of a region bounded by the polar curve \(r = f(\theta)\) and the rays \(\theta = a\) and \(\theta = b\) is:

\(A = \frac{1}{2}\int_a^b [f(\theta)]^2 \, d\theta\)

Example: Area in Polar Coordinates

Find the area enclosed by one petal of the rose curve \(r = 4\sin(3\theta)\).

One petal corresponds to \(\theta \in [0, \frac{\pi}{3}]\).

\(A = \frac{1}{2}\int_0^{\frac{\pi}{3}} [4\sin(3\theta)]^2 \, d\theta = 8\int_0^{\frac{\pi}{3}} \sin^2(3\theta) \, d\theta\)

\(= 8\int_0^{\frac{\pi}{3}} \frac{1 - \cos(6\theta)}{2} \, d\theta = 4\int_0^{\frac{\pi}{3}} [1 - \cos(6\theta)] \, d\theta\)

\(= 4\left[\theta - \frac{\sin(6\theta)}{6}\right]_0^{\frac{\pi}{3}} = 4\left[\frac{\pi}{3} - 0 - \frac{\sin(2\pi)}{6} + \frac{\sin(0)}{6}\right] = \frac{4\pi}{3}\)

The area of one petal is \(\frac{4\pi}{3}\) square units.

Vector-Valued Functions

Definition

A vector-valued function \(\vec{r}(t)\) has the form:

\(\vec{r}(t) = f(t)\vec{i} + g(t)\vec{j} + h(t)\vec{k}\)

Or in 2D: \(\vec{r}(t) = f(t)\vec{i} + g(t)\vec{j}\)

This can represent a parametric curve in space or a particle's position as a function of time.

Derivatives of Vector Functions

\(\vec{r}'(t) = f'(t)\vec{i} + g'(t)\vec{j} + h'(t)\vec{k}\)

The derivative \(\vec{r}'(t)\) represents the velocity vector.

The second derivative \(\vec{r}''(t)\) represents the acceleration vector.

Example: Motion Analysis with Vector Functions

A particle moves according to the position function \(\vec{r}(t) = t^2\vec{i} + 2t\vec{j}\) for \(t \geq 0\).

The velocity vector is \(\vec{v}(t) = \vec{r}'(t) = 2t\vec{i} + 2\vec{j}\).

The acceleration vector is \(\vec{a}(t) = \vec{r}''(t) = 2\vec{i} + 0\vec{j} = 2\vec{i}\).

The speed at time \(t\) is \(|\vec{v}(t)| = \sqrt{(2t)^2 + 2^2} = \sqrt{4t^2 + 4} = 2\sqrt{t^2 + 1}\).

At \(t = 3\), the speed is \(2\sqrt{3^2 + 1} = 2\sqrt{10} \approx 6.32\) units/time.

Introduction to Sequences and Series

Key Definitions

Sequence: An ordered list of numbers \(\{a_n\}\).

Series: The sum of the terms of a sequence \(\sum_{n=1}^{\infty} a_n\).

Convergent Sequence: A sequence with a finite limit as \(n\) approaches infinity.

Divergent Sequence: A sequence that doesn't have a finite limit.

Convergent Series: A series whose sequence of partial sums converges to a finite value.

Divergent Series: A series whose sequence of partial sums doesn't converge to a finite value.

Example: Convergence of Sequences

Determine whether the sequence \(\{a_n\} = \{\frac{2n+1}{n}\}\) converges or diverges.

\(\lim_{n \to \infty} \frac{2n+1}{n} = \lim_{n \to \infty} \left(2 + \frac{1}{n}\right) = 2 + 0 = 2\)

The sequence converges to 2.

Example: Partial Sums

Find the first four partial sums of the series \(\sum_{n=1}^{\infty} \frac{1}{n(n+1)}\).

We can rewrite using partial fractions: \(\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}\)

\(S_1 = \frac{1}{1} - \frac{1}{2} = 1 - \frac{1}{2} = \frac{1}{2}\)

\(S_2 = \frac{1}{1} - \frac{1}{2} + \frac{1}{2} - \frac{1}{3} = 1 - \frac{1}{3} = \frac{2}{3}\)

\(S_3 = \frac{1}{1} - \frac{1}{2} + \frac{1}{2} - \frac{1}{3} + \frac{1}{3} - \frac{1}{4} = 1 - \frac{1}{4} = \frac{3}{4}\)

\(S_4 = \frac{1}{1} - \frac{1}{2} + \frac{1}{2} - \frac{1}{3} + \frac{1}{3} - \frac{1}{4} + \frac{1}{4} - \frac{1}{5} = 1 - \frac{1}{5} = \frac{4}{5}\)

We notice a pattern: \(S_n = \frac{n}{n+1}\), which converges to 1 as \(n\) approaches infinity.
