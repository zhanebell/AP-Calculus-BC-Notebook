Exploring Accumulations of Change

The concept of accumulation forms the foundation of integral calculus. While derivatives give us instantaneous rates of change, integrals help us find the total accumulation of these changes over an interval.

Key Concept: Accumulation of Change

If \(f(x)\) represents a rate of change, then the accumulated change over the interval \([a, b]\) is given by \(\int_{a}^{b} f(x) \, dx\).

Examples:

  • If \(v(t)\) is velocity, \(\int_{a}^{b} v(t) \, dt\) represents total displacement.
  • If \(r(t)\) is flow rate, \(\int_{a}^{b} r(t) \, dt\) represents total volume.

Approximating Areas with Riemann Sums

Riemann sums allow us to approximate the area under a curve by dividing the region into simple shapes (usually rectangles) whose areas we can calculate.

Types of Riemann Sums

For a function \(f\) on the interval \([a, b]\) divided into \(n\) subintervals of equal width \(\Delta x = \frac{b-a}{n}\):

  1. Left Riemann Sum: Use left endpoint of each subinterval. \[ \sum_{i=1}^{n} f(a + (i-1)\Delta x) \cdot \Delta x \]
  2. Right Riemann Sum: Use right endpoint of each subinterval. \[ \sum_{i=1}^{n} f(a + i\Delta x) \cdot \Delta x \]
  3. Midpoint Riemann Sum: Use midpoint of each subinterval. \[ \sum_{i=1}^{n} f(a + (i-\frac{1}{2})\Delta x) \cdot \Delta x \ ]
  4. Trapezoidal Rule: Use the average of function values at endpoints of each subinterval. \[ \sum_{i=1}^{n} \frac{f(a + (i-1)\Delta x) + f(a + i\Delta x)}{2} \cdot \Delta x \ ]

Example

Approximate \(\int_{1}^{4} x^2 \, dx\) using 3 subintervals with a left Riemann sum.

\([a, b] = [1, 4]\) with \(n = 3\), so \(\Delta x = \frac{4-1}{3} = 1\)

Subintervals: \([1,2]\), \([2,3]\), and \([3,4]\)

Left endpoints: \(x_0 = 1\), \(x_1 = 2\), and \(x_2 = 3\)

Left Riemann Sum = \(f(1) \cdot 1 + f(2) \cdot 1 + f(3) \cdot 1\)

\(= 1^2 \cdot 1 + 2^2 \cdot 1 + 3^2 \cdot 1 = 1 + 4 + 9 = 14\)

The actual value is \(\int_{1}^{4} x^2 \, dx = \left[ \frac{x^3}{3} \right]_{1}^{4} = \frac{4^3}{3} - \frac{1^3}{3} = \frac{64 - 1}{3} = \frac{63}{3} = 21\)

Riemann Sums, Summation Notation, and Definite Integral Notation

From Riemann Sums to Definite Integrals

As the number of subintervals \(n\) approaches infinity, the Riemann sum approaches the definite integral:

\[ \int_{a}^{b} f(x) \, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^*) \Delta x \]

where \(x_i^*\) is any sample point in the \(i\)th subinterval.

Properties of the Definite Integral

  • \(\int_{a}^{b} [f(x) \pm g(x)] \, dx = \int_{a}^{b} f(x) \, dx \pm \int_{a}^{b} g(x) \, dx\)
  • \(\int_{a}^{b} k \cdot f(x) \, dx = k \cdot \int_{a}^{b} f(x) \, dx\) (where \(k\) is a constant)
  • \(\int_{a}^{b} f(x) \, dx = -\int_{b}^{a} f(x) \, dx\)
  • \(\int_{a}^{b} f(x) \, dx + \int_{b}^{c} f(x) \, dx = \int_{a}^{c} f(x) \, dx\)
  • If \(f(x) \geq 0\) for \(a \leq x \leq b\), then \(\int_{a}^{b} f(x) \, dx \geq 0\)
  • If \(f(x) \geq g(x)\) for \(a \leq x \leq b\), then \(\int_{a}^{b} f(x) \, dx \geq \int_{a}^{b} g(x) \, dx\)

The Fundamental Theorem of Calculus

Fundamental Theorem of Calculus, Part 1

If \(f\) is continuous on \([a, b]\), and \(F(x) = \int_{a}^{x} f(t) \, dt\), then \(F'(x) = f(x)\) for all \(x\) in \((a, b)\).

This means the derivative of the accumulation function equals the original function.

Fundamental Theorem of Calculus, Part 2

If \(f\) is continuous on \([a, b]\) and \(F\) is any antiderivative of \(f\), then:

\[ \int_{a}^{b} f(x) \, dx = F(b) - F(a) = \left. F(x) \right|_{a}^{b} \]

This connects differentiation and integration as inverse processes.

Example

Evaluate \(\int_{0}^{2} (3x^2 + 2x - 1) \, dx\) using the Fundamental Theorem of Calculus.

Find an antiderivative: \(F(x) = x^3 + x^2 - x + C\)

\(\int_{0}^{2} (3x^2 + 2x - 1) \, dx = F(2) - F(0)\)

\(= (2^3 + 2^2 - 2 + C) - (0^3 + 0^2 - 0 + C)\)

\(= (8 + 4 - 2) - 0 = 10\)

Interpreting the Behavior of Accumulation Functions

Accumulation Functions

Given a continuous function \(f\), the accumulation function is:

\[ F(x) = \int_{a}^{x} f(t) \, dt \]

Properties of accumulation functions:

  • \(F(a) = 0\) (since \(\int_{a}^{a} f(t) \, dt = 0\))
  • \(F'(x) = f(x)\) (by FTC Part 1)
  • If \(f(x) > 0\), then \(F(x)\) is increasing
  • If \(f(x) < 0\), then \(F(x)\) is decreasing
  • If \(f'(x) > 0\), then \(F(x)\) is concave up
  • If \(f'(x) < 0\), then \(F(x)\) is concave down

Example

If \(f(t) = \sin(t)\) and \(F(x) = \int_{0}^{x} f(t) \, dt\), determine:

  1. The intervals where \(F(x)\) is increasing or decreasing
  2. The intervals where \(F(x)\) is concave up or down

(a) \(F(x)\) is increasing when \(f(x) > 0\), which occurs when \(\sin(x) > 0\), or for \(x \in (0, \pi) + 2\pi n\) where \(n\) is an integer.

\(F(x)\) is decreasing when \(f(x) < 0\), which occurs when \(\sin(x) < 0\), or for \(x \in (\pi, 2\pi) + 2\pi n\) where \(n\) is an integer.

(b) \(F(x)\) is concave up when \(f'(x) > 0\), or when \(\cos(x) > 0\), which occurs for \(x \in (-\pi/2, \pi/2) + 2\pi n\).

\(F(x)\) is concave down when \(f'(x) < 0\), or when \(\cos(x) < 0\), which occurs for \(x \in (\pi/2, 3\pi/2) + 2\pi n\).

Applying Properties of Definite Integrals

Special Properties and Techniques

  1. Even and Odd Functions:
    • If \(f\) is even (\(f(-x) = f(x)\)), then \(\int_{-a}^{a} f(x) \, dx = 2 \int_{0}^{a} f(x) \, dx\)
    • If \(f\) is odd (\(f(-x) = -f(x)\)), then \(\int_{-a}^{a} f(x) \, dx = 0\)
  2. Average Value: The average value of \(f\) on \([a, b]\) is \(\frac{1}{b-a} \int_{a}^{b} f(x) \, dx\)
  3. Mean Value Theorem for Integrals: If \(f\) is continuous on \([a, b]\), there exists a point \(c\) in \([a, b]\) such that \(f(c) = \frac{1}{b-a} \int_{a}^{b} f(x) \, dx\)

Example

Evaluate \(\int_{-3}^{3} (x^2 + x^3) \, dx\) using the properties of even and odd functions.

\(x^2\) is an even function, so \(\int_{-3}^{3} x^2 \, dx = 2 \int_{0}^{3} x^2 \, dx\)

\(x^3\) is an odd function, so \(\int_{-3}^{3} x^3 \, dx = 0\)

Thus, \(\int_{-3}^{3} (x^2 + x^3) \, dx = 2 \int_{0}^{3} x^2 \, dx + 0\)

\(= 2 \cdot \left[ \frac{x^3}{3} \right]_{0}^{3} = 2 \cdot \left( \frac{27}{3} - 0 \right) = 2 \cdot 9 = 18\)

Finding Antiderivatives and Indefinite Integrals: Basic Rules and Notation

Indefinite Integral Notation

The indefinite integral \(\int f(x) \, dx\) represents the general antiderivative of \(f\):

\[ \int f(x) \, dx = F(x) + C \]

where \(F'(x) = f(x)\) and \(C\) is an arbitrary constant.

Basic Integration Rules

  1. \(\int k \cdot f(x) \, dx = k \int f(x) \, dx\) (where \(k\) is a constant)
  2. \(\int [f(x) \pm g(x)] \, dx = \int f(x) \, dx \pm \int g(x) \, dx\)
  3. \(\int x^n \, dx = \frac{x^{n+1}}{n+1} + C\), for \(n \neq -1\)
  4. \(\int \frac{1}{x} \, dx = \ln|x| + C\)
  5. \(\int e^x \, dx = e^x + C\)
  6. \(\int a^x \, dx = \frac{a^x}{\ln a} + C\), for \(a > 0, a \neq 1\)
  7. \(\int \sin x \, dx = -\cos x + C\)
  8. \(\int \cos x \, dx = \sin x + C\)
  9. \(\int \sec^2 x \, dx = \tan x + C\)
  10. \(\int \csc^2 x \, dx = -\cot x + C\)
  11. \(\int \sec x \tan x \, dx = \sec x + C\)
  12. \(\int \csc x \cot x \, dx = -\csc x + C\)

Example

Find \(\int (3x^2 - 2\sin x + 4e^x) \, dx\)

\(\int (3x^2 - 2\sin x + 4e^x) \, dx = 3\int x^2 \, dx - 2\int \sin x \, dx + 4\int e^x \, dx\)

\(= 3 \cdot \frac{x^3}{3} - 2 \cdot (-\cos x) + 4 \cdot e^x + C\)

\(= x^3 + 2\cos x + 4e^x + C\)

Integrating Using Substitution

U-Substitution Method

If \(u = g(x)\) and \(du = g'(x) \, dx\), then:

\[ \int f(g(x)) \cdot g'(x) \, dx = \int f(u) \, du \]

This corresponds to reversing the chain rule for differentiation.

Example 1: U-Substitution with Power Functions

Evaluate \(\int x(x^2 + 1)^5 \, dx\)

Let \(u = x^2 + 1\), then \(du = 2x \, dx\) or \(x \, dx = \frac{du}{2}\)

\(\int x(x^2 + 1)^5 \, dx = \int (x^2 + 1)^5 \cdot x \, dx = \int u^5 \cdot \frac{du}{2} = \frac{1}{2} \int u^5 \, du\)

\(= \frac{1}{2} \cdot \frac{u^6}{6} + C = \frac{u^6}{12} + C = \frac{(x^2 + 1)^6}{12} + C\)

Example 2: Trigonometric Substitution

Evaluate \(\int \cos^3 x \, dx\)

First, rewrite using the identity \(\cos^3 x = \cos^2 x \cdot \cos x = (1 - \sin^2 x) \cdot \cos x\)

\(\int \cos^3 x \, dx = \int (1 - \sin^2 x) \cdot \cos x \, dx\)

Let \(u = \sin x\), then \(du = \cos x \, dx\)

\(\int (1 - \sin^2 x) \cdot \cos x \, dx = \int (1 - u^2) \, du\)

\(= \int (1 - u^2) \, du = \int du - \int u^2 \, du\)

\(= u - \frac{u^3}{3} + C\)

\(= \sin x - \frac{\sin^3 x}{3} + C\)

Example 3: Inverse Trig Functions

Evaluate \(\int \frac{dx}{9 + 4x^2}\)

Rewrite as \(\int \frac{dx}{9 + 4x^2} = \int \frac{dx}{9(1 + (\frac{2x}{3})^2)} = \frac{1}{9} \int \frac{dx}{1 + (\frac{2x}{3})^2}\)

Using the formula \(\int \frac{dx}{1 + x^2} = \arctan x + C\), let \(u = \frac{2x}{3}\), so \(du = \frac{2}{3} dx\) or \(dx = \frac{3}{2} du\)

\(\frac{1}{9} \int \frac{dx}{1 + (\frac{2x}{3})^2} = \frac{1}{9} \int \frac{\frac{3}{2} du}{1 + u^2} = \frac{1}{6} \int \frac{du}{1 + u^2} = \frac{1}{6} \arctan u + C\)

\(= \frac{1}{6} \arctan(\frac{2x}{3}) + C\)
