Introduction

Today we'll explore the analytical applications of derivatives, including finding extrema, intervals of increase/decrease, concavity, and related rates.

Mean Value Theorem (MVT)

Mean Value Theorem

If \(f\) is continuous on [a,b] and differentiable on (a,b), then there exists at least one point \(c\) in (a,b) such that:

\[ f'(c) = \frac{f(b) - f(a)}{b - a} \]

Geometric interpretation: At some point in the interval, the tangent line to the curve is parallel to the secant line connecting the endpoints.

Example

For \(f(x) = x^3 - 3x + 2\) on \([-1, 2]\), verify the Mean Value Theorem.

\(f'(x) = 3x^2 - 3\)

\(\frac{f(2) - f(-1)}{2 - (-1)} = \frac{8 - 3 - (-1 + 3 + 2)}{3} = \frac{6 - 4}{3} = \frac{2}{3}\)

Set \(f'(c) = \frac{2}{3}\): \(3c^2 - 3 = \frac{2}{3}\)

\(3c^2 = \frac{2}{3} + 3 = \frac{2}{3} + \frac{9}{3} = \frac{11}{3}\)

\(c^2 = \frac{11}{9}\) so \(c = \pm\frac{\sqrt{11}}{3}\)

Since \(c\) must be in \((-1, 2)\) and \(\frac{\sqrt{11}}{3} \approx 1.1\), we have \(c = \frac{\sqrt{11}}{3}\).

Rolle's Theorem (Special Case of MVT)

If \(f\) is continuous on [a,b], differentiable on (a,b), and \(f(a) = f(b)\), then there exists at least one point \(c\) in (a,b) such that \(f'(c) = 0\).

Extreme Value Theorem and Critical Points

Extreme Value Theorem

If \(f\) is continuous on a closed interval [a,b], then \(f\) attains both a maximum and minimum value on [a,b].

Critical Points

A critical point of \(f\) is a value \(x = c\) in the domain of \(f\) where either:

  1. \(f'(c) = 0\), or
  2. \(f'(c)\) does not exist but \(f\) is continuous at \(c\).

Critical points are candidates for local extrema.

Types of Extrema

Local (Relative) Extrema: Values where the function is a maximum or minimum relative to nearby points.

Global (Absolute) Extrema: The highest and lowest values of the function over its entire domain.

Example

Find all critical points of \(f(x) = x^3 - 6x^2 + 9x + 1\).

\(f'(x) = 3x^2 - 12x + 9\)

Set \(f'(x) = 0\): \(3x^2 - 12x + 9 = 0\)

\(x^2 - 4x + 3 = 0\)

\((x - 1)(x - 3) = 0\)

So \(x = 1\) and \(x = 3\) are critical points.

Determining Intervals of Increase and Decrease

First Derivative Test for Intervals

For a differentiable function \(f\):

  • If \(f'(x) > 0\) on an interval, then \(f\) is increasing on that interval.
  • If \(f'(x) < 0\) on an interval, then \(f\) is decreasing on that interval.
  • If \(f'(x) = 0\) on an interval, then \(f\) is constant on that interval.

Example

For \(f(x) = x^3 - 6x^2 + 9x + 1\), determine the intervals where \(f\) is increasing or decreasing.

We found \(f'(x) = 3x^2 - 12x + 9\) with critical points at \(x = 1\) and \(x = 3\).

Testing regions:

  • For \(x < 1\): Test \(x = 0\) → \(f'(0) = 9 > 0\), so \(f\) is increasing on \((-\infty, 1)\).
  • For \(1 < x < 3\): Test \(x = 2\) → \(f'(2) = 3(4) - 12(2) + 9 = 12 - 24 + 9 = -3 < 0\), so \(f\) is decreasing on \((1, 3)\).
  • For \(x > 3\): Test \(x = 4\) → \(f'(4) = 3(16) - 12(4) + 9 = 48 - 48 + 9 = 9 > 0\), so \(f\) is increasing on \((3, \infty)\).

First Derivative Test for Local Extrema

First Derivative Test

If \(c\) is a critical point of a continuous function \(f\) and \(f\) is differentiable near \(c\) (except possibly at \(c\)):

  1. If \(f'(x)\) changes from positive to negative at \(x = c\), then \(f\) has a local maximum at \(x = c\).
  2. If \(f'(x)\) changes from negative to positive at \(x = c\), then \(f\) has a local minimum at \(x = c\).
  3. If \(f'(x)\) does not change sign at \(x = c\), then \(f\) has no local extremum at \(x = c\).

Example (Continued)

Classify the critical points of \(f(x) = x^3 - 6x^2 + 9x + 1\) as local maxima, local minima, or neither.

At \(x = 1\): \(f'(x)\) changes from positive to negative, so \(f\) has a local maximum at \(x = 1\).

At \(x = 3\): \(f'(x)\) changes from negative to positive, so \(f\) has a local minimum at \(x = 3\).

Local maximum value: \(f(1) = 1 - 6 + 9 + 1 = 5\)

Local minimum value: \(f(3) = 27 - 54 + 27 + 1 = 1\)

Finding Global Extrema

Candidates Test

To find global extrema of a continuous function \(f\) on a closed interval [a,b]:

  1. Find all critical points of \(f\) in (a,b).
  2. Evaluate \(f\) at each critical point in (a,b).
  3. Evaluate \(f\) at the endpoints \(x = a\) and \(x = b\).
  4. The largest of these values is the global maximum, and the smallest is the global minimum.

Example

Find the global extrema of \(f(x) = x^3 - 6x^2 + 9x + 1\) on the interval \([0, 4]\).

Critical points in \([0, 4]\): \(x = 1\) and \(x = 3\)

Evaluate at critical points and endpoints:

  • \(f(0) = 0 - 0 + 0 + 1 = 1\)
  • \(f(1) = 1 - 6 + 9 + 1 = 5\)
  • \(f(3) = 27 - 54 + 27 + 1 = 1\)
  • \(f(4) = 64 - 96 + 36 + 1 = 5\)

Global maximum: \(f(1) = f(4) = 5\) (occurs at both \(x = 1\) and \(x = 4\))

Global minimum: \(f(0) = f(3) = 1\) (occurs at both \(x = 0\) and \(x = 3\))

Determining Concavity

Second Derivative Test for Concavity

For a twice-differentiable function \(f\):

  • If \(f''(x) > 0\) on an interval, then \(f\) is concave upward on that interval.
  • If \(f''(x) < 0\) on an interval, then \(f\) is concave downward on that interval.

An inflection point occurs at \(x = c\) if \(f''(c) = 0\) or \(f''(c)\) does not exist, and \(f''\) changes sign at \(c\).

Example

Find the intervals of concavity and inflection points for \(f(x) = x^3 - 6x^2 + 9x + 1\).

\(f'(x) = 3x^2 - 12x + 9\)

\(f''(x) = 6x - 12\)

Set \(f''(x) = 0\): \(6x - 12 = 0 \Rightarrow x = 2\)

Testing regions:

  • For \(x < 2\): \(f''(1) = 6 - 12 = -6 < 0\), so \(f\) is concave downward on \((-\infty, 2)\).
  • For \(x > 2\): \(f''(3) = 18 - 12 = 6 > 0\), so \(f\) is concave upward on \((2, \infty)\).

Since \(f''(x)\) changes sign at \(x = 2\), there is an inflection point at \(x = 2\).

Inflection point: \((2, f(2)) = (2, 8 - 24 + 18 + 1) = (2, 3)\)

Second Derivative Test for Extrema

Second Derivative Test

If \(f'(c) = 0\) and \(f\) is twice differentiable near \(c\):

  1. If \(f''(c) > 0\), then \(f\) has a local minimum at \(x = c\).
  2. If \(f''(c) < 0\), then \(f\) has a local maximum at \(x = c\).
  3. If \(f''(c) = 0\), the test is inconclusive.

Example

Use the Second Derivative Test to classify the critical points of \(f(x) = x^3 - 6x^2 + 9x + 1\).

Critical points: \(x = 1\) and \(x = 3\)

\(f''(x) = 6x - 12\)

\(f''(1) = 6 - 12 = -6 < 0\), so \(f\) has a local maximum at \(x = 1\).

\(f''(3) = 18 - 12 = 6 > 0\), so \(f\) has a local minimum at \(x = 3\).

This confirms our results from the First Derivative Test.

Curve Sketching

Steps for Curve Sketching

  1. Find the domain of the function.
  2. Find any symmetry, asymptotes, or special points.
  3. Find the critical points and determine where the function is increasing/decreasing.
  4. Find where the concavity changes and identify inflection points.
  5. Plot key points and sketch the curve.

Example

Sketch the curve \(f(x) = x^3 - 6x^2 + 9x + 1\).

Domain: All real numbers

Behavior as \(x \to \pm\infty\): Since the leading term is \(x^3\), \(f(x) \to \infty\) as \(x \to \infty\) and \(f(x) \to -\infty\) as \(x \to -\infty\).

Critical points: \(x = 1\) (local max) and \(x = 3\) (local min)

Inflection point: \(x = 2\)

Key points: \((0, 1)\), \((1, 5)\), \((2, 3)\), \((3, 1)\), \((4, 5)\)

The function is:

  • Increasing on \((-\infty, 1)\) and \((3, \infty)\)
  • Decreasing on \((1, 3)\)
  • Concave downward on \((-\infty, 2)\)
  • Concave upward on \((2, \infty)\)

With this information, we can sketch the curve.

Connecting Functions and Their Derivatives

Function-Derivative Relationships

  • If \(f'(c) = 0\), then the tangent line to \(f\) at \(x = c\) is horizontal.
  • If \(f'(x) > 0\) on an interval, then the graph of \(f\) is rising on that interval.
  • If \(f'(x) < 0\) on an interval, then the graph of \(f\) is falling on that interval.
  • If \(f''(x) > 0\) on an interval, then the graph of \(f\) is concave up (smiling) on that interval.
  • If \(f''(x) < 0\) on an interval, then the graph of \(f\) is concave down (frowning) on that interval.
  • If \(f''(c) = 0\) and \(f''\) changes sign at \(c\), then \(f\) has an inflection point at \(x = c\).

Example

Given the graph of \(f'(x)\) below, describe the behavior of \(f(x)\).

[This would include a graph of \(f'(x)\) in an actual implementation]

For a sample \(f'(x)\) that is positive on \((-\infty, -1)\), negative on \((-1, 3)\), and positive on \((3, \infty)\):

  • \(f(x)\) is increasing on \((-\infty, -1)\)
  • \(f(x)\) is decreasing on \((-1, 3)\)
  • \(f(x)\) is increasing on \((3, \infty)\)
  • \(f(x)\) has a local maximum at \(x = -1\)
  • \(f(x)\) has a local minimum at \(x = 3\)

Optimization Problems

Steps for Solving Optimization Problems

  1. Identify what needs to be maximized or minimized.
  2. Express this quantity as a function of one variable.
  3. Determine the domain relevant to the problem.
  4. Find critical points within the domain.
  5. Evaluate the function at critical points and endpoints to find the optimal value.
  6. Verify your answer makes sense in context.

Example

Find the dimensions of a rectangle with perimeter 100 units that has the maximum possible area.

Let \(x\) = length and \(y\) = width of the rectangle.

Perimeter: \(2x + 2y = 100\) so \(y = 50 - x\).

Area: \(A = xy = x(50 - x) = 50x - x^2\)

Domain: \(0 < x < 50\) (both dimensions must be positive)

\(A'(x) = 50 - 2x\)

Set \(A'(x) = 0\): \(50 - 2x = 0 \Rightarrow x = 25\)

Since \(A''(x) = -2 < 0\), this is a maximum.

So \(x = 25\) and \(y = 50 - 25 = 25\).

The rectangle with maximum area is a square with sides of 25 units.

Maximum area: \(A = 25 \times 25 = 625\) square units.

Behaviors of Implicit Relations

Analyzing Implicit Functions

For an implicit function \(F(x, y) = 0\):

  • To find \(\frac{dy}{dx}\), use implicit differentiation
  • To find critical points, solve \(\frac{dy}{dx} = 0\) or points where \(\frac{dy}{dx}\) doesn't exist
  • To find concavity, calculate \(\frac{d^2y}{dx^2}\) and analyze its sign

Example

Analyze the implicit curve \(x^2 + y^2 = 25\) (a circle of radius 5).

Taking the derivative with respect to \(x\):

\(2x + 2y\frac{dy}{dx} = 0\)

\(\frac{dy}{dx} = -\frac{x}{y}\)

Critical points (where \(\frac{dy}{dx} = 0\)): When \(x = 0\), so \((0, 5)\) and \((0, -5)\).

Points where \(\frac{dy}{dx}\) doesn't exist: When \(y = 0\), so \((5, 0)\) and \((-5, 0)\).

These are the "top", "bottom", "right", and "left" points of the circle, as expected.
