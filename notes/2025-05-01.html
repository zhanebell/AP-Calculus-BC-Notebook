The Chain Rule

Chain Rule Concept

The chain rule is used to differentiate composite functions \(f(g(x))\).

Chain Rule Formula

If \(y = f(u)\) and \(u = g(x)\), then:

\(\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}\)

Or using function notation:

\((f \circ g)'(x) = f'(g(x)) \cdot g'(x)\)

Chain Rule Example

Find the derivative of \(y = \sin(x^2)\).

Let \(u = x^2\) and \(y = \sin(u)\).

\(\frac{dy}{du} = \cos(u)\) and \(\frac{du}{dx} = 2x\)

\(\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} = \cos(u) \cdot 2x = \cos(x^2) \cdot 2x = 2x\cos(x^2)\)

Common Patterns Using Chain Rule

  • \(\frac{d}{dx}[\sin(g(x))] = \cos(g(x)) \cdot g'(x)\)
  • \(\frac{d}{dx}[e^{g(x)}] = e^{g(x)} \cdot g'(x)\)
  • \(\frac{d}{dx}[\ln(g(x))] = \frac{g'(x)}{g(x)}\) where \(g(x) > 0\)
  • \(\frac{d}{dx}[g(x)^n] = n \cdot g(x)^{n-1} \cdot g'(x)\)

Implicit Differentiation

Concept of Implicit Differentiation

Implicit differentiation allows us to find derivatives when the relationship between variables is defined implicitly rather than explicitly as \(y = f(x)\).

Process of Implicit Differentiation

  1. Differentiate both sides of the equation with respect to \(x\).
  2. When differentiating terms with \(y\), use the chain rule by multiplying by \(\frac{dy}{dx}\).
  3. Solve for \(\frac{dy}{dx}\).

Implicit Differentiation Example

Find \(\frac{dy}{dx}\) for \(x^2 + y^2 = 25\).

Differentiating both sides with respect to \(x\):

\(2x + 2y\frac{dy}{dx} = 0\)

Solving for \(\frac{dy}{dx}\):

\(2y\frac{dy}{dx} = -2x\)

\(\frac{dy}{dx} = -\frac{x}{y}\)

Applications of Implicit Differentiation

  • Finding derivatives for relations that cannot be easily expressed as \(y = f(x)\).
  • Working with equations of conics (circles, ellipses, etc.).
  • Finding derivatives of inverse functions.
  • Related rates problems.

Differentiation of Inverse Functions

Derivative of an Inverse Function

If \(f\) is a differentiable function with an inverse function \(f^{-1}\), and \(f'(f^{-1}(x)) \neq 0\), then:

\((f^{-1})'(x) = \frac{1}{f'(f^{-1}(x))}\)

Example of Differentiating an Inverse Function

Find the derivative of \(f^{-1}(x)\) at \(x = 8\) if \(f(x) = x^3 + 2\) and \(f^{-1}(8) = 2\).

We know that \(f'(x) = 3x^2\)

\((f^{-1})'(8) = \frac{1}{f'(f^{-1}(8))} = \frac{1}{f'(2)} = \frac{1}{3(2)^2} = \frac{1}{12}\)

Derivatives of Inverse Trigonometric Functions

Common Inverse Trigonometric Derivatives

  • \(\frac{d}{dx}[\arcsin(x)] = \frac{1}{\sqrt{1-x^2}}\) for \(|x| < 1\)
  • \(\frac{d}{dx}[\arccos(x)] = -\frac{1}{\sqrt{1-x^2}}\) for \(|x| < 1\)
  • \(\frac{d}{dx}[\arctan(x)] = \frac{1}{1+x^2}\) for all real \(x\)
  • \(\frac{d}{dx}[\text{arccot}(x)] = -\frac{1}{1+x^2}\) for all real \(x\)
  • \(\frac{d}{dx}[\text{arcsec}(x)] = \frac{1}{|x|\sqrt{x^2-1}}\) for \(|x| > 1\)
  • \(\frac{d}{dx}[\text{arccsc}(x)] = -\frac{1}{|x|\sqrt{x^2-1}}\) for \(|x| > 1\)

Example with Inverse Trigonometric Functions

Find the derivative of \(y = x^2\arctan(x) - \ln\sqrt{1+x^2}\).

Using product rule for the first term:

\(\frac{d}{dx}[x^2\arctan(x)] = 2x\arctan(x) + x^2 \cdot \frac{1}{1+x^2}\)

For the second term:

\(\frac{d}{dx}[\ln\sqrt{1+x^2}] = \frac{d}{dx}[\frac{1}{2}\ln(1+x^2)] = \frac{1}{2} \cdot \frac{2x}{1+x^2} = \frac{x}{1+x^2}\)

Therefore:

\(\frac{dy}{dx} = 2x\arctan(x) + \frac{x^2}{1+x^2} - \frac{x}{1+x^2}\)

\(\frac{dy}{dx} = 2x\arctan(x) + \frac{x^2 - x}{1+x^2}\)

Selecting Procedures for Calculating Derivatives

Decision Flow for Derivative Techniques

  • Is it a basic function? → Use basic derivative rules
  • Is it a sum/difference of functions? → Use sum/difference rules
  • Is it a product of functions? → Use product rule
  • Is it a quotient of functions? → Use quotient rule
  • Is it a composition of functions? → Use chain rule
  • Is it an equation with \(x\) and \(y\) mixed? → Use implicit differentiation
  • Is it an inverse function? → Use inverse function derivative formula

Technique Selection Example

Find the derivative of \(y = \frac{e^x \sin(x^2)}{x^3 + 1}\)

This is a quotient, so we use the quotient rule:

\(\frac{dy}{dx} = \frac{(e^x \sin(x^2))' \cdot (x^3 + 1) - (e^x \sin(x^2)) \cdot (x^3 + 1)'}{(x^3 + 1)^2}\)

For \((e^x \sin(x^2))'\), we use the product rule:

\((e^x \sin(x^2))' = e^x \sin(x^2) + e^x \cdot (2x\cos(x^2))\)

For \((x^3 + 1)'\), we get \(3x^2\)

The full derivative calculation follows by substituting these parts into the quotient rule.

Higher-Order Derivatives

Definition of Higher-Order Derivatives

The second derivative is the derivative of the first derivative: \(f''(x) = \frac{d}{dx}[f'(x)]\)

Similarly, the third derivative is: \(f'''(x) = \frac{d}{dx}[f''(x)]\)

In general, the \(n^{th}\) derivative is denoted as \(f^{(n)}(x)\)

Calculating Higher-Order Derivatives

Find \(f''(x)\) for \(f(x) = 3x^4 - 2x^3 + 5x - 1\)

\(f'(x) = 12x^3 - 6x^2 + 5\)

\(f''(x) = 36x^2 - 12x\)

\(f'''(x) = 72x - 12\)

\(f^{(4)}(x) = 72\)

\(f^{(5)}(x) = 0\)

Applications of Higher-Order Derivatives

  • Analyzing concavity and inflection points
  • Taylor series and polynomial approximations
  • Motion analysis (position, velocity, acceleration, jerk)
  • Differential equations
