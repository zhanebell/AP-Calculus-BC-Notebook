Introduction to Limits

The concept of a limit is fundamental to calculus. It describes the behavior of a function as its input approaches a particular value.

Understanding Limits

Intuitive Definition

A limit describes the value that a function approaches as the input approaches some value:

\[ \lim_{x \to a} f(x) = L \]

This is read as "the limit of \(f(x)\) as \(x\) approaches \(a\) equals \(L\)".

One-Sided Limits

Left-hand limit

\(\lim_{x \to a^-} f(x)\) - approaching from values less than \(a\)

Right-hand limit

\(\lim_{x \to a^+} f(x)\) - approaching from values greater than \(a\)

Two-Sided Limit Existence Theorem

A two-sided limit exists only when both one-sided limits exist and are equal:

\[ \lim_{x \to a} f(x) = L \text{ if and only if } \lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L \]

Limit Laws

Basic Limit Laws

For functions \(f\) and \(g\) where \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\):

  1. Sum Rule: \(\lim_{x \to a} [f(x) \pm g(x)] = L \pm M\)
  2. Product Rule: \(\lim_{x \to a} [f(x) \cdot g(x)] = L \cdot M\)
  3. Quotient Rule: \(\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{L}{M}\), if \(M \neq 0\)
  4. Constant Multiple Rule: \(\lim_{x \to a} [c \cdot f(x)] = c \cdot L\), for any constant \(c\)
  5. Power Rule: \(\lim_{x \to a} [f(x)]^n = L^n\), for integer \(n\) (if \(n < 0\), then \(L \neq 0\))
  6. Root Rule: \(\lim_{x \to a} \sqrt[n]{f(x)} = \sqrt[n]{L}\), for odd \(n\) or for even \(n\) if \(L > 0\)

Special Limit Formulas

Trigonometric Limits

\(\lim_{x \to 0} \frac{\sin x}{x} = 1\)

\(\lim_{x \to 0} \frac{1-\cos x}{x} = 0\)

\(\lim_{x \to 0} \frac{\tan x}{x} = 1\)

Exponential Limits

\(\lim_{x \to 0} \frac{e^x - 1}{x} = 1\)

\(\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e\)

\(\lim_{x \to 0} \frac{\ln(1+x)}{x} = 1\)

Indeterminate Forms

Common Indeterminate Forms

\(\frac{0}{0}, \frac{\infty}{\infty}, 0 \cdot \infty, \infty - \infty, 0^0, 1^{\infty}, \infty^0\)

These forms require techniques like L'Hôpital's rule, algebraic manipulation, or other limit strategies to evaluate.

Infinite Limits and Limits at Infinity

Infinite Limits

When the function values grow without bound as \(x\) approaches \(a\):

\(\lim_{x \to a} f(x) = \infty\) or \(\lim_{x \to a} f(x) = -\infty\)

Limits at Infinity

Describes the behavior of a function as \(x\) grows without bound:

\(\lim_{x \to \infty} f(x) = L\) or \(\lim_{x \to -\infty} f(x) = L\)

Limits of Rational Functions

For a rational function \(f(x) = \frac{P(x)}{Q(x)}\), where \(P(x) = a_n x^n + \ldots + a_1 x + a_0\) and \(Q(x) = b_m x^m + \ldots + b_1 x + b_0\):

  • If \(n < m\), then \(\lim_{x \to \infty} f(x) = 0\)
  • If \(n = m\), then \(\lim_{x \to \infty} f(x) = \frac{a_n}{b_m}\)
  • If \(n > m\), then \(\lim_{x \to \infty} f(x) = \infty\) or \(-\infty\) (depending on signs of \(a_n\) and \(b_m\))

Continuity

Definition of Continuity

A function \(f\) is continuous at a point \(x = a\) if:

  1. \(f(a)\) is defined
  2. \(\lim_{x \to a} f(x)\) exists
  3. \(\lim_{x \to a} f(x) = f(a)\)

Types of Discontinuities

  • Removable discontinuity: The limit exists but \(f(a)\) is either undefined or not equal to the limit
  • Jump discontinuity: Left and right limits exist but are not equal
  • Infinite discontinuity: The limit approaches infinity from at least one side

Key Theorems on Continuity

Intermediate Value Theorem

If \(f\) is continuous on [a,b] and \(k\) is any value between \(f(a)\) and \(f(b)\), then there exists at least one \(c\) in [a,b] such that \(f(c) = k\).

Extreme Value Theorem

If \(f\) is continuous on a closed interval [a,b], then \(f\) attains both a maximum and minimum value on [a,b].

Squeeze Theorem

Squeeze Theorem (Sandwich Theorem)

If \(g(x) \leq f(x) \leq h(x)\) for all \(x\) near \(a\) (except possibly at \(a\)), and if \(\lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L\), then \(\lim_{x \to a} f(x) = L\).

Introduction to Differentiation

The Fundamental Question of Calculus

Can change occur at an instant? Differentiation answers this question by quantifying instantaneous rates of change.

Average Rate of Change

The average rate of change of a function \(f\) over an interval \([a, a+h]\) is:

\(\frac{f(a+h) - f(a)}{h}\)

Instantaneous Rate of Change (Derivative)

The instantaneous rate of change at \(x = a\) is defined as the limit of the average rate of change as the interval approaches zero:

\(f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}\)

Derivative Notation

Multiple Notations for Derivatives

For a function \(y = f(x)\):

  • Lagrange notation: \(f'(x)\)
  • Leibniz notation: \(\frac{dy}{dx}\) or \(\frac{d}{dx}f(x)\)
  • Newton notation: \(\dot{y}\) (for time derivatives)
  • Prime notation (for higher derivatives): \(f''(x), f'''(x), f^{(n)}(x)\)

Estimating Derivatives

From Graphs

The derivative \(f'(a)\) at a point is the slope of the tangent line to the curve at \(x = a\).

From Tables

For a table of values, approximate \(f'(a)\) using difference quotients with values near \(a\):

\(f'(a) \approx \frac{f(a+h) - f(a)}{h}\) for small \(h\)

Differentiability and Continuity

Connection Between Differentiability and Continuity

If a function \(f\) is differentiable at \(x = a\), then \(f\) is continuous at \(x = a\).

However, the converse is not true: continuity does not guarantee differentiability.

Conditions for Non-Differentiability

A function is not differentiable at points where:

  • There is a vertical tangent (infinite slope)
  • There is a corner or cusp (left and right derivatives exist but are not equal)
  • There is a discontinuity

Basic Derivative Rules

Power Rule

\(\frac{d}{dx}[x^n] = nx^{n-1}\) for any real number \(n\)

Constant Rule

\(\frac{d}{dx}[c] = 0\) for any constant \(c\)

Constant Multiple Rule

\(\frac{d}{dx}[cf(x)] = c \cdot f'(x)\) for any constant \(c\)

Sum and Difference Rules

\(\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)\)

Common Derivatives

Trigonometric Functions

  • \(\frac{d}{dx}[\sin x] = \cos x\)
  • \(\frac{d}{dx}[\cos x] = -\sin x\)
  • \(\frac{d}{dx}[\tan x] = \sec^2 x\)
  • \(\frac{d}{dx}[\cot x] = -\csc^2 x\)
  • \(\frac{d}{dx}[\sec x] = \sec x \tan x\)
  • \(\frac{d}{dx}[\csc x] = -\csc x \cot x\)

Exponential and Logarithmic Functions

  • \(\frac{d}{dx}[e^x] = e^x\)
  • \(\frac{d}{dx}[a^x] = a^x \ln a\)
  • \(\frac{d}{dx}[\ln x] = \frac{1}{x}\)
  • \(\frac{d}{dx}[\log_a x] = \frac{1}{x \ln a}\)

Product and Quotient Rules

Product Rule

\(\frac{d}{dx}[f(x) \cdot g(x)] = f'(x) \cdot g(x) + f(x) \cdot g'(x)\)

Quotient Rule

\(\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x) \cdot g(x) - f(x) \cdot g'(x)}{[g(x)]^2}\) where \(g(x) \neq 0\)

Applying Quotient Rule

Find \(\frac{d}{dx}[\tan x]\) using the quotient rule:

\(\tan x = \frac{\sin x}{\cos x}\)

\(\frac{d}{dx}[\tan x] = \frac{\cos x \cdot \cos x - \sin x \cdot (-\sin x)}{\cos^2 x} = \frac{\cos^2 x + \sin^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} = \sec^2 x\)
