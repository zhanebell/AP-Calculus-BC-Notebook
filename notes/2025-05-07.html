Introduction

Today we'll focus on the various real-world applications of integration, including area, volume, arc length, and more.

Average Value of a Function on an Interval

Average Value Formula

The average value of a continuous function \(f(x)\) on the interval \([a,b]\) is given by:

\[ f_{avg} = \frac{1}{b-a} \int_{a}^{b} f(x) \, dx \]

This represents the height of a rectangle with the same area as under the curve on \([a,b]\).

Example

Find the average value of \(f(x) = x^2\) on the interval \([0,3]\).

\(f_{avg} = \frac{1}{3-0} \int_{0}^{3} x^2 \, dx = \frac{1}{3} \left[ \frac{x^3}{3} \right]_{0}^{3} = \frac{1}{3} \cdot \frac{27}{3} = 3\)

The average value of \(f(x) = x^2\) on \([0,3]\) is 3.

Mean Value Theorem for Integrals

If \(f\) is continuous on \([a,b]\), then there exists at least one point \(c \in [a,b]\) such that:

\[ f(c) = \frac{1}{b-a} \int_{a}^{b} f(x) \, dx \]

That is, the function equals its average value at some point in the interval.

Connecting Position, Velocity, and Acceleration Using Integrals

Key Relationships

If \(s(t)\), \(v(t)\), and \(a(t)\) represent position, velocity, and acceleration functions respectively:

  • \(v(t) = s'(t)\) and \(s(t) = \int v(t) \, dt + C\)
  • \(a(t) = v'(t)\) and \(v(t) = \int a(t) \, dt + C\)

The displacement over interval \([t_1, t_2]\) is given by:

\[ s(t_2) - s(t_1) = \int_{t_1}^{t_2} v(t) \, dt \]

The change in velocity over interval \([t_1, t_2]\) is given by:

\[ v(t_2) - v(t_1) = \int_{t_1}^{t_2} a(t) \, dt \]

Example

A particle moves along a line with acceleration \(a(t) = 6t - 2\) m/s². If \(v(0) = 5\) m/s and \(s(0) = 3\) m, find the position function \(s(t)\).

First, find the velocity function by integrating acceleration:

\(v(t) = \int a(t) \, dt = \int (6t - 2) \, dt = 3t^2 - 2t + C_1\)

Using \(v(0) = 5\):

\(v(0) = 0 - 0 + C_1 = 5 \Rightarrow C_1 = 5\)

So \(v(t) = 3t^2 - 2t + 5\)

Now, find position by integrating velocity:

\(s(t) = \int v(t) \, dt = \int (3t^2 - 2t + 5) \, dt = t^3 - t^2 + 5t + C_2\)

Using \(s(0) = 3\):

\(s(0) = 0 - 0 + 0 + C_2 = 3 \Rightarrow C_2 = 3\)

Therefore, \(s(t) = t^3 - t^2 + 5t + 3\)

Using Accumulation Functions and Definite Integrals in Applied Contexts

Net Change Theorem

The net change in quantity \(F\) whose rate of change is \(f\) over interval \([a,b]\) is:

\[ F(b) - F(a) = \int_{a}^{b} f(x) \, dx \]

Applications include:

  • Total distance traveled: \(\int_{t_1}^{t_2} |v(t)| \, dt\)
  • Net change in temperature: \(\int_{t_1}^{t_2} r(t) \, dt\) where \(r(t)\) is the rate of change of temperature
  • Work done by a variable force: \(\int_{a}^{b} F(x) \, dx\)

Example

Water flows into a tank at a rate of \(r(t) = 10 - 0.5t^2\) gallons per minute, where \(t\) is measured in minutes. How much water flows into the tank during the first 4 minutes?

The total amount of water is the integral of the rate function:

\(\int_{0}^{4} (10 - 0.5t^2) \, dt = \left[ 10t - \frac{0.5t^3}{3} \right]_{0}^{4}\)

\(= 10(4) - \frac{0.5(4^3)}{3} - 0 = 40 - \frac{32}{3} = 40 - 10.67 = 29.33\)

Approximately 29.33 gallons of water flow into the tank during the first 4 minutes.

Finding the Area Between Curves

Area Between Curves (Functions of x)

The area between curves \(y = f(x)\) and \(y = g(x)\) from \(x = a\) to \(x = b\), where \(f(x) \geq g(x)\) on \([a,b]\), is:

\[ A = \int_{a}^{b} [f(x) - g(x)] \, dx \]

Area Between Curves (Functions of y)

The area between curves \(x = f(y)\) and \(x = g(y)\) from \(y = c\) to \(y = d\), where \(f(y) \geq g(y)\) on \([c,d]\), is:

\[ A = \int_{c}^{d} [f(y) - g(y)] \, dy \]

Example 1: Functions of x

Find the area of the region bounded by \(y = x^2\) and \(y = x + 2\).

First, find the points of intersection:

\(x^2 = x + 2\)

\(x^2 - x - 2 = 0\)

\((x - 2)(x + 1) = 0\)

\(x = 2\) or \(x = -1\)

For \(x \in [-1, 2]\), we need to determine which function is greater:

At \(x = 0\): \(x^2 = 0\) and \(x + 2 = 2\), so \(x + 2 > x^2\)

The area is:

\(A = \int_{-1}^{2} [(x + 2) - x^2] \, dx = \int_{-1}^{2} (x + 2 - x^2) \, dx\)

\(= \left[ \frac{x^2}{2} + 2x - \frac{x^3}{3} \right]_{-1}^{2}\)

\(= \left[ 2 + 4 - \frac{8}{3} \right] - \left[ \frac{1}{2} - 2 - \frac{-1}{3} \right]\)

\(= \left[ 2 + 4 - \frac{8}{3} \right] - \left[ \frac{1}{2} - 2 + \frac{1}{3} \right]\)

\(= 6 - \frac{8}{3} - \frac{1}{2} + 2 - \frac{1}{3}\)

\(= 8 - \frac{8}{3} - \frac{3}{6} - \frac{2}{6}\)

\(= 8 - \frac{8}{3} - \frac{5}{6}\)

\(= \frac{9}{2}\)

The area is \(\frac{9}{2}\) square units.

Example 2: Functions of y

Find the area of the region bounded by \(x = y^2\) and \(x = 4\) for \(0 \leq y \leq 2\).

Since these are functions of \(y\), we integrate with respect to \(y\):

\(A = \int_{0}^{2} [4 - y^2] \, dy = \left[ 4y - \frac{y^3}{3} \right]_{0}^{2}\)

\(= \left[ 8 - \frac{8}{3} \right] - 0 = 8 - \frac{8}{3} = \frac{24 - 8}{3} = \frac{16}{3}\)

The area is \(\frac{16}{3}\) square units.

Multiple Intersection Points

When curves intersect at more than two points, divide the region into subregions at each intersection point. For each subregion, determine which curve is above the other, then find the area of each subregion separately.

Example 3: Multiple Intersections

Find the area of the region bounded by \(y = \sin(x)\) and \(y = \cos(x)\) from \(x = 0\) to \(x = \pi\).

First, find intersection points by solving \(\sin(x) = \cos(x)\):

\(\sin(x) = \cos(x)\)

\(\sin(x) - \cos(x) = 0\)

\(\tan(x) = 1\)

\(x = \frac{\pi}{4}\) (in the first quadrant)

\(x = \frac{5\pi}{4}\) (in the third quadrant, outside our interval)

So there's one intersection point in our interval at \(x = \frac{\pi}{4}\).

For \(0 \leq x \leq \frac{\pi}{4}\), \(\cos(x) \geq \sin(x)\).

For \(\frac{\pi}{4} \leq x \leq \pi\), \(\sin(x) \geq \cos(x)\).

The total area is:

\(A = \int_{0}^{\frac{\pi}{4}} [\cos(x) - \sin(x)] \, dx + \int_{\frac{\pi}{4}}^{\pi} [\sin(x) - \cos(x)] \, dx\)

\(= \left[ \sin(x) + \cos(x) \right]_{0}^{\frac{\pi}{4}} + \left[ -\cos(x) - \sin(x) \right]_{\frac{\pi}{4}}^{\pi}\)

\(= \left[ \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2} \right] - [0 + 1] + \left[ 1 - 0 \right] - \left[ -\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2} \right]\)

\(= \sqrt{2} - 1 + 1 + \sqrt{2} = 2\sqrt{2}\)

The area is \(2\sqrt{2}\) square units.

Volumes with Cross-Sections

Volume Formula with Cross-Sections

If \(A(x)\) is the area of a cross-section perpendicular to the x-axis at point \(x\), then the volume of the solid from \(x = a\) to \(x = b\) is:

\[ V = \int_{a}^{b} A(x) \, dx \]

Common cross-sectional shapes:

  • Squares: \(A(x) = [f(x)]^2\)
  • Rectangles: \(A(x) = f(x) \cdot g(x)\)
  • Triangles: \(A(x) = \frac{1}{2} \cdot \text{base} \cdot \text{height}\)
  • Semicircles: \(A(x) = \frac{\pi [f(x)]^2}{2}\)

Example: Square Cross-Sections

Find the volume of a solid with square cross-sections perpendicular to the x-axis, where the base of the solid is the region bounded by \(y = \sqrt{x}\), \(y = 0\), and \(x = 4\).

The square cross-section at position \(x\) has side length equal to the height of the curve at \(x\), which is \(\sqrt{x}\).

The area of the square cross-section is \(A(x) = [\sqrt{x}]^2 = x\).

The volume is:

\(V = \int_{0}^{4} x \, dx = \left[ \frac{x^2}{2} \right]_{0}^{4} = \frac{16}{2} - 0 = 8\)

The volume of the solid is 8 cubic units.

Volume with Disc Method

Disc Method Formula

For a solid of revolution formed by rotating the region between \(y = f(x)\) and the x-axis from \(x = a\) to \(x = b\) around the x-axis:

\[ V = \pi \int_{a}^{b} [f(x)]^2 \, dx \]

For rotation around the y-axis:

\[ V = 2\pi \int_{a}^{b} x \cdot f(x) \, dx \]

Example: Rotation Around x-axis

Find the volume of the solid formed by rotating the region bounded by \(y = x^2\) and \(y = 0\) from \(x = 0\) to \(x = 2\) around the x-axis.

Using the disc method:

\(V = \pi \int_{0}^{2} [x^2]^2 \, dx = \pi \int_{0}^{2} x^4 \, dx = \pi \left[ \frac{x^5}{5} \right]_{0}^{2}\)

\(= \pi \cdot \frac{32}{5} = \frac{32\pi}{5}\)

The volume of the solid is \(\frac{32\pi}{5}\) cubic units.

Rotation Around Other Axes

For rotation around the horizontal line \(y = k\):

\[ V = \pi \int_{a}^{b} [f(x) - k]^2 \, dx \]

For rotation around the vertical line \(x = k\):

\[ V = 2\pi \int_{a}^{b} (x - k) \cdot f(x) \, dx \]

Example: Rotation Around y = 2

Find the volume of the solid formed by rotating the region bounded by \(y = \sqrt{x}\), \(y = 0\), and \(x = 4\) around the line \(y = 2\).

Using the formula for rotation around \(y = k\):

\(V = \pi \int_{0}^{4} [(\sqrt{x} - 2)]^2 \, dx = \pi \int_{0}^{4} (x - 4\sqrt{x} + 4) \, dx\)

\(= \pi \left[ \frac{x^2}{2} - 4 \cdot \frac{2x^{3/2}}{3} + 4x \right]_{0}^{4}\)

\(= \pi \left[ 8 - \frac{8 \cdot 8}{3} + 16 - 0 \right]\)

\(= \pi \left[ 24 - \frac{64}{3} \right] = \pi \left[ \frac{72 - 64}{3} \right] = \frac{8\pi}{3}\)

The volume of the solid is \(\frac{8\pi}{3}\) cubic units.

Volume with Washer Method

Washer Method Formula

For a solid of revolution formed by rotating the region between \(y = f(x)\) and \(y = g(x)\) from \(x = a\) to \(x = b\) around the x-axis, where \(f(x) \geq g(x) \geq 0\):

\[ V = \pi \int_{a}^{b} \left([f(x)]^2 - [g(x)]^2\right) \, dx \ ]

For rotation around the y-axis:

\[ V = 2\pi \int_{a}^{b} x \cdot (f(x) - g(x)) \, dx \]

Example: Washer Method Around x-axis

Find the volume of the solid formed by rotating the region bounded by \(y = x^2\) and \(y = x\) from \(x = 0\) to \(x = 1\) around the x-axis.

In the interval \([0,1]\), \(x \geq x^2\), so \(f(x) = x\) and \(g(x) = x^2\).

Using the washer method:

\(V = \pi \int_{0}^{1} \left(x^2 - (x^2)^2\right) \, dx = \pi \int_{0}^{1} (x^2 - x^4) \, dx\)

\(= \pi \left[ \frac{x^3}{3} - \frac{x^5}{5} \right]_{0}^{1} = \pi \left(\frac{1}{3} - \frac{1}{5} \right) = \pi \left(\frac{5 - 3}{15} \right) = \frac{2\pi}{15}\)

The volume of the solid is \(\frac{2\pi}{15}\) cubic units.

Washer Method for Rotation Around Other Axes

For rotation around the horizontal line \(y = k\):

\[ V = \pi \int_{a}^{b} \left([f(x) - k]^2 - [g(x) - k]^2\right) \, dx \]

For rotation around the vertical line \(x = k\):

\[ V = 2\pi \int_{a}^{b} (x - k) \cdot (f(x) - g(x)) \, dx \]

Example: Washer Method Around y-axis

Find the volume of the solid formed by rotating the region bounded by \(y = x^2\) and \(y = x\) from \(x = 0\) to \(x = 1\) around the y-axis.

Using the washer method for rotation around the y-axis:

\(V = 2\pi \int_{0}^{1} x \cdot (x - x^2) \, dx = 2\pi \int_{0}^{1} (x^2 - x^3) \, dx\)

\(= 2\pi \left[ \frac{x^3}{3} - \frac{x^4}{4} \right]_{0}^{1} = 2\pi \left(\frac{1}{3} - \frac{1}{4} \right) = 2\pi \left(\frac{4 - 3}{12} \right) = \frac{\pi}{6}\)

The volume of the solid is \(\frac{\pi}{6}\) cubic units.

Arc Length and Distance Traveled

Arc Length Formula

The arc length of a curve \(y = f(x)\) from \(x = a\) to \(x = b\), where \(f\) is differentiable on \([a,b]\), is:

\[ L = \int_{a}^{b} \sqrt{1 + [f'(x)]^2} \, dx \]

For a curve \(x = g(y)\) from \(y = c\) to \(y = d\):

\[ L = \int_{c}^{d} \sqrt{1 + [g'(y)]^2} \, dy \]

Example: Arc Length

Find the arc length of the curve \(y = \frac{x^{3/2}}{3} + \frac{1}{2x^{1/2}}\) from \(x = 1\) to \(x = 4\).

\(f'(x) = \frac{3x^{1/2}}{6} - \frac{1}{4x^{3/2}} = \frac{1}{2}x^{1/2} - \frac{1}{4}x^{-3/2}\)

\([f'(x)]^2 = \left(\frac{1}{2}x^{1/2} - \frac{1}{4}x^{-3/2}\right)^2\)

This would be challenging to integrate directly, but by design, this function simplifies:

\([f'(x)]^2 = \frac{1}{4}x + \frac{1}{16}x^{-3} - \frac{1}{4}x^{-1} = \frac{x^4 + 1 - 4x^2}{16x^3}\)

With this particular function, \(1 + [f'(x)]^2 = \frac{16x^3 + x^4 + 1 - 4x^2}{16x^3} = \frac{(x^2 - 1)^2}{16x^3} + 1\)

And by design: \(\sqrt{1 + [f'(x)]^2} = \frac{x^2 + 1}{2x^{3/2}}\)

So the arc length is:

\(L = \int_{1}^{4} \frac{x^2 + 1}{2x^{3/2}} \, dx = \frac{1}{2}\int_{1}^{4} \left(x^{1/2} + x^{-3/2}\right) \, dx\)

\(= \frac{1}{2} \left[ \frac{2x^{3/2}}{3} - \frac{2}{x^{1/2}} \right]_{1}^{4}\)

\(= \frac{1}{2} \left[ \left(\frac{2(4^{3/2})}{3} - \frac{2}{2}\right) - \left(\frac{2}{3} - 2\right) \right]\)

\(= \frac{1}{2} \left[ \left(\frac{2 \cdot 8}{3} - 1\right) - \left(\frac{2}{3} - 2\right) \right]\)

\(= \frac{1}{2} \left[ \left(\frac{16}{3} - 1\right) - \left(\frac{2 - 6}{3}\right) \ \right]\)

\(= \frac{1}{2} \left[ \frac{16 - 3}{3} - \frac{-4}{3} \right] = \frac{1}{2} \left[ \frac{13 + 4}{3} \right] = \frac{17}{6}\)

The arc length is \(\frac{17}{6}\) units.

Distance Traveled vs. Displacement

For a particle moving along a line with position function \(s(t)\) from \(t = a\) to \(t = b\):

  • Total distance traveled = \(\int_{a}^{b} |v(t)| \, dt\) where \(v(t) = s'(t)\)
  • Displacement = \(s(b) - s(a) = \int_{a}^{b} v(t) \, dt\)

Example: Distance Traveled

A particle moves along a line with velocity \(v(t) = t^2 - 4t + 3\) m/s. Find the total distance traveled by the particle from \(t = 0\) to \(t = 5\).

First, determine when \(v(t) = 0\):

\(t^2 - 4t + 3 = 0\)

\((t - 1)(t - 3) = 0\)

\(t = 1\) or \(t = 3\)

We need to find when \(v(t)\) changes sign:

  • For \(0 \leq t < 1\): \(v(0) = 3 > 0\), so \(v(t) > 0\)
  • For \(1 < t < 3\): \(v(2) = 4 - 8 + 3 = -1 < 0\), so \(v(t) < 0\)
  • For \(3 < t \leq 5\): \(v(4) = 16 - 16 + 3 = 3 > 0\), so \(v(t) > 0\)

Total distance traveled:

\(D = \int_{0}^{1} v(t) \, dt + \int_{1}^{3} -v(t) \, dt + \int_{3}^{5} v(t) \, dt\)

\(= \int_{0}^{1} (t^2 - 4t + 3) \, dt + \int_{1}^{3} -(t^2 - 4t + 3) \, dt + \int_{3}^{5} (t^2 - 4t + 3) \, dt\)

\(= \left[ \frac{t^3}{3} - 2t^2 + 3t \right]_{0}^{1} + \left[ -\frac{t^3}{3} + 2t^2 - 3t \right]_{1}^{3} + \left[ \frac{t^3}{3} - 2t^2 + 3t \right]_{3}^{5}\)

\(= \left(\frac{1}{3} - 2 + 3\right) + \left(-\frac{27}{3} + 18 - 9 + \frac{1}{3} - 2 + 3\right) + \left(\frac{125}{3} - 50 + 15 - \frac{27}{3} + 18 - 9\right)\)

\(= \frac{4}{3} + \left(-9 + 10\right) + \left(\frac{125 - 27}{3} - 50 + 15 + 18 - 9\right)\)

\(= \frac{4}{3} + 1 + \left(\frac{98}{3} - 26\right) = \frac{4}{3} + 1 + \left(\frac{98 - 78}{3}\right) = \frac{4}{3} + 1 + \frac{20}{3} = \frac{4 + 3 + 20}{3} = \frac{27}{3} = 9\)

The total distance traveled is 9 meters.
